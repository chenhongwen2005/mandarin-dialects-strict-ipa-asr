# 验证指标（实测）

以下指标均使用 `out_mandarin_finetune_ipa130/best.pt` 在推理脚本 `src/infer.py --eval` 上
对指定验证集解码（贪心）得到，解码与训练保持完全一致（原始波形输入、`frontend.dither=0`、
bf16 编码器前向、头权重从旧版权重残留命名自动映射为 `ctc_head.*`）。

| 声调准确率（标签无关） | 0.8915 |

## 指标定义

- **TER**：预测与参考的 token 级编辑距离 / 参考长度。
- **ACC**：预测 token 序列与参考序列完全相等的比例。
- **TACC**：逐样本 `1 - 编辑距离 / max(预测长, 参考长)` 再平均。
- **声调准确率**：用 `vocab_mandarin_ipa_tone_combined.json` 把每个 IPA 音节映射到调类 1–5
  （轻声=5），对预测与参考逐位比声调。该指标与具体音素标注写法无关，是对声调识别能力的公平度量。
